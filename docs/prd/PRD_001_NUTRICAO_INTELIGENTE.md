# PRD 001 — Nutrição Inteligente

## Objetivo
Fundação local-first, tipada e rastreável para biblioteca, planejamento, execução, receitas, compras e estoque.

## Regras
Macros exigem proveniência; plano nunca é consumo; execução exige ação; histórico e Score são imutáveis por importação; falha de bootstrap é diagnosticável e repetível; ausência de fonte vira pendência, não dado fictício. Fora do escopo: telas e precisão clínica.
