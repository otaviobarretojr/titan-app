# Onboarding e Perfil

Sem perfil, o TITAN mostra “Bem-vindo ao TITAN” com ações para criar perfil, importar Projeto TITAN, restaurar backup ou continuar depois.

Continuar depois persiste `onboardingStatus: skipped` em `appPreferences`, libera o Dashboard e permite retomar a configuração pela área Conta e Configurações.

O perfil preserva `createdAt` em edições e atualiza apenas `updatedAt`.
