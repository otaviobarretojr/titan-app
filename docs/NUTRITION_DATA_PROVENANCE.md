# Proveniência nutricional

Todo alimento registra tipo/nome/ID/versão/referência/acesso da fonte, quantidade/unidade de referência, preparo, confiança e verificação opcional. O pipeline rejeita ausência, números negativos e chaves compostas duplicadas. Registros de rótulo preservam porção original. A auditoria `npm run nutrition:audit-provenance` impede macro órfão.
