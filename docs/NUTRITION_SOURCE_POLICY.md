# Política de fontes nutricionais

A proveniência é obrigatória. A prioridade é TACO/UNICAMP para alimentos brasileiros, USDA FoodData Central como complemento importado de modo controlado e rótulo para produtos específicos. Personalizados usam `user_custom`; estimativas do coach são explícitas, de baixa confiança e último recurso. TBCA não é copiada, raspada, incorporada nem redistribuída sem autorização. O app não raspa fontes em runtime, não contém chave USDA e funciona offline depois de uma importação. TITAN cura, mas nunca é a fonte original. Estes dados não oferecem precisão clínica.
