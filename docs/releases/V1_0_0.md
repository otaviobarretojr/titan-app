# TITAN v1.0.0 — Release Oficial

**Versão:** 1.0.0  
**Tag lógica:** `v1.0.0`  
**Data:** 5 de agosto de 2026  
**Release name:** TITAN v1.0.0 — Release Oficial

## Release Summary

A Sprint 018 promove o TITAN à primeira versão oficial. A entrega é uma etapa de release engineering, validação, documentação e estabilização final, sem introduzir novas funcionalidades, sem alterar contratos públicos e sem migrar schemas IndexedDB.

## Features consolidadas

- Dashboard mobile-first com Score TITAN, Coach prioritário, refeições, treino, cardio, hidratação, sono e pendências.
- Treino com sessões, séries, descanso, volume, recordes e progressão local.
- Nutrição com refeições planejadas, registros parciais/completos, macros e hidratação.
- Cardio, evolução corporal, saúde, sono, analytics, relatórios, notificações locais e backup local/nuvem manual.
- PWA instalável, cache offline, Service Worker gerado por Workbox e dados persistidos no IndexedDB.

## Architecture

- Fonte operacional principal: IndexedDB/Dexie.
- Supabase: opcional, manual e restrito a backup em nuvem quando configurado.
- Rotas: `React.lazy`/`Suspense` para lazy loading e code splitting por módulo.
- PWA: manifesto versionado, `NetworkFirst` para navegação e `CacheFirst` limitado para imagens.
- Notificações: consentimento explícito, Inbox local e limitações de segundo plano documentadas.

## Performance

A revisão confirma preservação de lazy loading, code splitting, navegação memoizada no shell, componentes reutilizáveis, skeletons leves e ausência de novas dependências pesadas. O build de produção deve continuar validando os artefatos PWA e o bundle sem regressões intencionais.

## Accessibility

A versão mantém foco visível, labels acessíveis revisados na Sprint 017, semântica de dialog/status para restauração em nuvem e mensagens operacionais, além de suporte a `prefers-reduced-motion`.

## Known Limitations

- Notificações de sistema em segundo plano dependem das restrições do navegador; sem Push API/backend, a Inbox local é a fonte confiável.
- Backup em nuvem é manual e opcional; não há sincronização automática, merge multi-dispositivo ou criptografia ponta a ponta implementada.
- Health Connect, Galaxy Watch, IA conversacional, multiusuário, sincronização automática e portal de personal trainer permanecem no roadmap 2.0.
- Testes manuais em dispositivos reais devem ser repetidos antes de cada publicação pública.
