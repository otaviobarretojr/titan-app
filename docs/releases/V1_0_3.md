# TITAN v1.0.3

Primeira release utilizável do TITAN: onboarding, perfil completo, planos independentes, importação segura pelo serviço único `titanFileService`, dashboard baseado em planos ativos, configurações completas, tema persistido, Sobre, changelog interno e backup compatível.

Formato TITAN aceito: envelope `schema: "TITAN"`, `schemaVersion: "1.0"`, tipo `profile`, `workout`, `nutrition`, `cardio`, `supplements` ou `project` e `payload` validado antes da confirmação.
