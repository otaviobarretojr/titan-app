# TITAN v0.9.0-rc.1

## Objetivo

Primeiro Release Candidate baseado na auditoria do projeto real.

## Alterações

- Rotas convertidas para carregamento sob demanda.
- Bundle principal dividido por módulo.
- Tela de carregamento acessível entre rotas.
- Versão elevada para `0.9.0-rc.1`.
- Validação completa preservada: ESLint, TypeScript, build, PWA e release.

## Resultado esperado

O aplicativo baixa apenas o núcleo inicial e carrega treino, nutrição, cardio, evolução, saúde, analytics e demais áreas quando necessárias.
