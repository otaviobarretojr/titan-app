# TITAN — Checklist Beta

## Escopo auditado

- [x] Dashboard: Score, recomendação prioritária, hidratação rápida, cards e estados sem dados.
- [x] Treino: início, continuidade, séries, descanso, conclusão e histórico derivado.
- [x] Nutrição: refeições planejadas, registro parcial, macros, hidratação e detalhe de refeição.
- [x] Cardio: início, registro, conclusão, pace, esforço e histórico.
- [x] Evolução: medidas, bioimpedância opcional, fotos locais otimizadas, filtros e exclusões confirmadas.
- [x] Saúde: métricas, exames, sintomas, sono e recuperação.
- [x] Coach: insights locais, evidências, tendências e dados insuficientes.
- [x] Analytics e Relatórios: filtros, gráficos, timeline, exportações JSON/CSV/PDF locais.
- [x] Notificações: consentimento explícito, preferências, Inbox local e limitações de segundo plano.
- [x] Conta: Supabase opcional, sessão por e-mail, backup manual, restauração confirmada e modo offline.
- [x] Backup local: exportação, restauração transacional, diagnóstico e reset confirmado.
- [x] PWA: manifest, base do GitHub Pages, precache, update prompt, offline e cache de imagens.
